# Competitive research, November 2026

Reading material on where Shipmater stands against the newest logistics startups, and what to build to catch up.

1. **[What's latest on the YC logistics list](01-yc-logistics-whats-latest.md):** who the new companies are, who competes with Shipmater, five patterns, the late-2026 market, and where Shipmater stands.
2. **[Production features Shipmater is missing](02-production-features-missing.md):** 21 non-AI features in priority order (P1 blocks production, P2 needed to compete, P3 differentiators), each with what exists today.
3. **[AI features as an add-on layer](03-ai-addon-layer.md):** 14 AI assistants for shippers, carriers and operations, how the layer is built, legal guardrails, build order and packaging.
4. **[Competitor feature matrix](04-competitor-matrix.md):** Shipmater against FleetWorks, Peer, Lanesurf, Manifold Freight, Cartage, GETASAP, TrueMile and chrt across 39 features, then a detailed build note for each gap Shipmater can close, with sizes and a build order. Spreadsheet copy: [competitor-matrix.csv](competitor-matrix.csv).

**Data:** [yc-logistics-companies.csv](yc-logistics-companies.csv) lists the 50 newest companies from the YC logistics directory (2023 to Fall 2026 batches), each rated Direct, Adjacent or Not relevant to Shipmater. The directory lists 113 in total; the older 63 load only by scrolling a live browser and were not collected.

Funding figures come from press and data aggregators, which often disagree; each document says where. Check primary sources before quoting a number externally.
